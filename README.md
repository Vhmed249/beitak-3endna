# 🏠 بيتك عندنا

منصة عقارات سودانية متكاملة

## 📱 الميزات
- البحث المتقدم عن العقارات
- إضافة العقارات مع الصور
- المفضلة
- التواصل عبر واتساب
- لوحة تحكم المشرف
- إشعارات فورية
- توثيق المستخدمين

## 🛠️ التقنيات المستخدمة
- Flutter
- Firebase (Auth, Firestore, Storage, Messaging)
- Provider

## 📦 التثبيت
1. `flutter pub get`
2. `flutter run`
